# Portafolio, versión 2

Misma información que `portfolio` (los archivos de `src/data/` son idénticos),
con otro diseño: la terminal de pago. Un campo azul ultramar, un voucher de
autorización impreso en papel térmico como elemento principal y un explorador
de skills que resalta los proyectos que usan cada tecnología.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # revisa tipos y genera dist/
```

Para quedarte con una sola versión, copia `src/data/` de una a otra: los datos
son compatibles en ambas.
